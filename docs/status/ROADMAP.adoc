= ZeroInflatedCounts.jl Roadmap

== Current status

Version 0.1.0. Phase *incubating*, maturity *experimental* (both recorded on the
`status` clause of `ZeroInflatedCounts.jl_chora.deed`).

Only the method-conditions specification exists
(`docs/method-conditions/zero-inflation-and-hurdle.adoc`). Nothing is
implemented, tested against R, or proved yet.

== Milestones

[cols="3,1",options="header"]
|===
| Milestone | Done

| Method-conditions specification for hurdle NB and ZINB | yes
| `hurdle_nb` and `zinb` via R `pscl`, with a Julia likelihood oracle in tests | no
| Known-answer tests against `pscl`, simulation recovery, negative controls | no
| Agda proofs: hurdle separability, truncation normaliser, ZINB zero probability | no
| Thin adapter PR into MetaManifold-WebUI (route, panel, config keys, dependency pinned by commit) | no
|===

== Next actions

. The owner approves the method-catalogue amendment that admits NB, hurdle NB
  and ZINB for sequencing data.
. Implement `hurdle_nb` and `zinb` against the conditions document.

== Not planned here

* Single-visit occupancy: not identifiable. A replicate-only (K ≥ 2) design is
  planned separately.
* A production Julia reimplementation of `pscl`: the Julia likelihood is a test
  oracle only.
