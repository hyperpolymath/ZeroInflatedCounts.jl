= machine-readable Pillar
:toc:

This pillar holds the repository's machine-readable metadata: the records
that let tools and agents read this project's state, boundaries and
obligations without parsing prose.

[IMPORTANT]
====
*Single normative source.* The grammar for the record family in this pillar
is `1-formats/deed/spec/DEED-GRAMMAR-SPEC.adoc` in
https://github.com/hyperpolymath/standards[hyperpolymath/standards]. That
document is the only place the syntax, semantics and typechecking rules are
defined. Every other mention of the format across the estate — including
every README in this tree — is a *pointer* to it, never a restatement.

The repository's own record is the repo deed at the repository root,
`ZeroInflatedCounts.jl_chora.deed`.
====

== Contents

`descriptiles/`:: The provisioning praxis deed. What this repository *is*
and what state it is *in* is the repo deed at the root. See
`descriptiles/README.adoc`.

`self-validating/`:: k9 validation contracts (Kennel, Yard, Hunt) and
their templates. See `self-validating/README.adoc`.

`policies/`:: Policy inputs for the maintenance audit. The maintenance
axes and checklist are `docs/governance/MAINTENANCE-CHECKLIST.adoc`.
