= Descriptiles

The descriptive record of this repository (what it *is* and what state it
is *in*) is the repo deed at the repository root,
`ZeroInflatedCounts.jl_chora.deed`. Its grammar is
`1-formats/deed/spec/abnf/deed.abnf` in
https://github.com/hyperpolymath/standards[hyperpolymath/standards]; the
clauses follow the mappings in `1-formats/deed/mappings/` there. Its
clauses are the identity fields, `clade`, `forges`, `lineage`, `status`,
`meta`, `ecosystem` and `agentic`. Milestones and next actions are in
`docs/status/ROADMAP.adoc`.

This directory holds one file:

`provisioning_praxis.deed`:: The provisioning praxis deed (DEED grammar,
`praxis-deed` form).

`anchors/`:: Empty; identity and purpose are in the repo deed. See its README.
